# 🍞 Fermentando Afeto

O Fermentando Afeto é um projeto individual desenvolvido para a disciplina de Projeto Individual da São Paulo Tech School.
A plataforma utiliza a panificação como tema central, oferecendo um ambiente para compartilhamento de receitas, interação entre usuários e visualização de dados por meio de dashboards.

## Funcionalidades

- Cadastro de usuários
- Login
- Área do usuário
- Fórum de interação
- Receitas de panificação
- Calculadora de proporções para receitas
- Dashboard com indicadores

## Tecnologias Utilizadas

### Front-end
- HTML
- CSS
- JavaScript

### Back-end
- Node.js

### Banco de Dados
- MySQL

### Dashboard
- Web Data Viz

### Ferramentas
- VS Code
- GitHub

### Infraestrutura
